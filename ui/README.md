# Bangla Authorship Attribution Web UI

Web interface for the Bangla authorship attribution and auditable style fingerprinting system (KUET CSE 4122 NLP Laboratory).

## Prerequisites

The models must be trained and cached in `artifacts/models/` (generated by running Notebook 04 or `scripts/run_notebooks.py`).

## Quickstart

### 1. Install UI Dependencies
Make sure you are in the repository root with the project's virtual environment:

**Windows (PowerShell):**
```powershell
Set-Location "E:\NLP Project\Bangla-author-fingerprinting"
.\.venv\Scripts\python.exe -m pip install -r ui/requirements.txt
```

**macOS / Linux:**
```bash
.venv/bin/python -m pip install -r ui/requirements.txt
```

---

### 2. Start the Server

**Windows (PowerShell):**
```powershell
Set-Location "E:\NLP Project\Bangla-author-fingerprinting"
$env:PYTHONIOENCODING="utf-8"
.\.venv\Scripts\python.exe -m uvicorn ui.server:app --host 127.0.0.1 --port 8000 --reload
```

**macOS / Linux:**
```bash
.venv/bin/python -m uvicorn ui.server:app --host 127.0.0.1 --port 8000 --reload
```

---

### 3. Open in Browser
Open your browser and navigate to:
```
http://127.0.0.1:8000
```

---

## Features & Auditable Interface

* **Two Paradigms Side-by-Side:**
  * **Discriminative (Linear SVM):** Margin over runner-up and exact linear contribution breakdown (\(w_i \times x_i\)).
  * **Generative (Language Models):** Perplexity under per-author character 5-gram models (lower = better fit).
* **Auditable Evidence First:**
  * Leads with human-checkable features (function words, POS sequence patterns, and structural scalars).
  * Collapsible toggle for raw character n-gram contributions with word boundary indicators (`␣`).
* **Stylistic Register Axis (Sadhu vs. Chalit):**
  * Visual gauge positioning the passage on the classical literary (*Sadhu*) vs colloquial (*Chalit*) spectrum.
* **Honesty & Domain Limits Built-in:**
  * Visual warning for short passages (<80 tokens).
  * High-visibility alert when paradigms disagree (low confidence).
  * Explicit closed-set, ~83% empirical accuracy, and 1820–1951 literary domain disclaimers.
